# Referência visual

Esta pasta é reservada aos assets originais do jogo.

A captura de referência compartilhada na conversa foi usada somente para orientar a composição da interface (HUD superior, painel de equipamentos, navegação lateral, mar e navio). Ela não é carregada como textura, sprite ou imagem de fundo do jogo.

Nenhum arquivo de imagem estava presente no repositório no momento da implementação. Adicione aqui os sprites originais quando estiverem disponíveis.
