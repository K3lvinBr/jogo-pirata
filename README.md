# Corsários do Caribe

RPG 2D mobile de gerenciamento e navegação pirata em tempo real/idle, construído com Expo, React Native, TypeScript e React Native Web.

## Desenvolvimento

```bash
npm install
npm run web
```

## Plataformas

- Web: Vite + React Native Web
- iOS e Android: Expo

## Estado do MVP

Estrutura inicial em desenvolvimento: painel principal, mapa do Caribe, navegação baseada em timestamps, recursos, inventário e equipamentos.
